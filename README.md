# Sprint_7 — API-тесты для сервиса «Яндекс.Самокат»

Проект с автоматизированными тестами на Python + requests для проверки API учебного сервиса «Яндекс.Самокат» (https://qa-scooter.praktikum-services.ru/docs/).
Разработан в рамках курса Яндекс Практикума, спринт «API-тестирование».

## Протестированные эндпоинты

- **Создание курьера** (`POST /api/v1/courier`) — успешное создание, дубликат, обязательные поля, коды и тело ответа.
- **Логин курьера** (`POST /api/v1/courier/login`) — успешная авторизация, неверный логин/пароль, отсутствие обязательных полей, несуществующий пользователь.
- **Создание заказа** (`POST /api/v1/orders`) — параметризованные тесты с разными наборами цветов (BLACK, GREY, оба, без цвета). Проверка наличия `track` в ответе.
- **Список заказов** (`GET /api/v1/orders`) — проверка структуры ответа (наличие поля `orders`).

## Запуск тестов

1. Установите зависимости:
   pip install -r requirements.txt
2. Запустите все тесты с сохранением данных для Allure:
   pytest tests/ --alluredir=allure-results
3. Просмотрите отчёт локально:
   allure serve allure-results

## Особенности реализации

- Независимость тестов: каждый тест использует уникальные данные (случайная генерация логинов/паролей), созданные в фикстурах, и удаляет их после выполнения.
- Параметризация: там, где требуется протестировать несколько вариантов входных данных (обязательные поля, цвета заказа), используется @pytest.mark.parametrize.
- Allure-отчёт: все ключевые шаги обёрнуты в @allure.step, что делает отчёт наглядным.
- Таймауты: все HTTP-запросы выполняются с timeout=10 для предотвращения зависаний.
- Отсутствие лишнего: в методах API оставлены только эндпоинты, необходимые для тестов.
